The native Paint ribbon includes drawing, selection, path, stamp, pattern, reshape and Spirograph tools, with 22 language packs and bundled fonts.

These packages use standalone GUI.Forms and its live-buffer canvas. All four native builds must pass CTest, style checks, packaging and isolated packaged startup before publication. SHA256SUMS contains the checksum of each package.

| Platform | Package and requirements |
| --- | --- |
| Windows x64 | Extract the entire ZIP and run PlanPaint/plan-paint.exe. Windows 10 or newer. |
| Apple Silicon Mac | Open the PKG installer, then launch Plan Paint from Applications. macOS 14 or newer. The application is ad-hoc signed; the installer is unsigned and not notarized. |
| Linux x64 / ARM64 | Extract the complete archive and launch PlanPaint/Plan Paint. Ubuntu 24.04 or a compatible newer glibc system, with X11 or XWayland. |

macOS may require approval in System Settings → Privacy & Security. Platform tests run on hosted Windows, macOS and Ubuntu runners; the macOS minimum version is also audited across all packaged libraries.
