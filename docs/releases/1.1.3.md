# Plan Paint 1.1.3

Plan Paint 1.1.3 adds selectable drawing smoothness, clearer path editing, and expanded Deluxe-style Spirograph controls while preserving direct editing of the raster canvas.

## Drawing and path editing

- Choose **Crisp**, the existing **Smooth**, or **4× Smooth** for lines, polygons and paths. The 4× mode renders at higher resolution and downsamples with alpha weighting; bounded tiles keep memory use controlled.
- Enable **Edit nodes** to drag path junctions with the primary mouse button. Blank clicks add nothing in this mode. **Continue path** returns to construction.
- Click an existing curved segment to reveal its square handles. Hover and active highlights clarify which control will move. Overlapping targets choose the nearest handle, and dragging preserves the grab offset.
- Each drag is one Undo step. Undo also ends an interrupted handle drag. The in-app help explains the workflow in all 22 language catalogs.

## Spirograph

- Resize the apparatus relative to the paper with **Scale** or its canvas handle. Moving and resizing the guide carries a seated wheel without depositing ink.
- **Lift wheel** permits free placement while preserving rotation. An amber outline identifies a detached wheel; **Operate** becomes available again when the wheel is seated on its guide. Repositioning does not draw a connecting line.
- The catalog includes the paired 144/96 and 150/105 rings, all 15 Deluxe circular wheel counts, Rack 150, Bar 40, Eye 60, Triangle 54 and Quad 60. Numbered-hole selection and **Load Primary / Load Alt** reduce precise pointer targeting.
- Quad rolls along rounded tips and pivots between adjacent endpoints. It supports the two kit-ring interiors, with eight and seven repeats respectively. A roughly 0.27% guide-dependent size adjustment matches those repeating patterns. Other guides and outside rolling are disabled for Quad.

Shaped-wheel outlines and hole coordinates are visually close approximations, not measured molded-part replicas. Eye and Triangle perimeter choices follow or are consistent with the kit pattern charts. See the [Spirograph documentation](https://github.com/falseywinchnet/plan-paint/blob/v1.1.3/docs/SPIROGRAPH.md) for geometry and compatibility details.

## Native platform improvements

Windows accessibility self references and Alt+F4 dispatch are corrected in the pinned GUI.Forms dependency. Runtime resources follow the executable even with a custom build output directory. Native recovery tests use isolated snapshots. The release workflow builds and tests Windows x64, Linux x64, Linux ARM64 and macOS ARM64 independently.

macOS requires version 26 or newer. The Mac application is ad-hoc signed; the installer is unsigned and not notarized. Linux requires X11 or XWayland. Windows 7 operating-system compatibility and Intel Mac builds have not been verified.
