# Plan Paint 1.1.1

Plan Paint 1.1.1 fixes missing translated text on Windows, makes language selection easier to recover, and reduces package and font-memory overhead.

## Windows text and ribbon labels

Ribbon captions made entirely from characters outside the primary UI font could disappear. The Windows text resolver now preserves valid fallback-only layouts, including Russian tab names. It uses the bundled Carlito face for Cyrillic and the supplied Arabic, Hebrew and Indic faces when needed. Longer translated captions fit their ribbon buttons.

## Language selection

Settings shows every language choice when the window has room. A visible scrollbar appears when the list needs more space. In non-English interfaces, **Help! English!** appears beside Help. Its confirmation stays in English; OK saves English as the application language and asks for a restart. The picture remains open so it can be saved first. Cancel leaves the preference unchanged.

## Smaller packages and fewer font copies

The macOS and Linux renderer shares immutable file mappings between rasterization and text shaping instead of retaining full-font heap copies. Glyph caches and other rendering resources still use memory. This is a reduction in font-storage overhead, not a fixed total-RAM promise.

Packaging removes unneeded symbols from executables and runtime libraries. macOS uses improved installer compression and Windows uses maximum ZIP deflate compression. Every bundled font and all 22 language packs remain included.

## Compatibility

Existing settings, recovery records and pictures remain compatible. The Forms interface remains the only released frontend. macOS requires version 26 or newer and uses an ad-hoc signature without Developer ID notarization. Linux requires X11 or XWayland. Native operating-system dialogs follow the system language. Independent translation proofreading and end-to-end assistive-technology user testing remain ongoing.
