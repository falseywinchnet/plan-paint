# Plan Paint 1.1

Release candidate preparation. The published download remains 1.0.0 until platform packages have passed release validation.

Plan Paint 1.1 brings a multilingual interface and additional ways to draw without holding a mouse button. The familiar native Forms ribbon keeps selection, text, polygons, editable paths and brushes close at hand for quick edits, memes and drawing.

## Languages

The application reads the operating system's preferred languages and chooses a supported match. Settings can override that choice; restart after changing languages. English is compiled in, and missing translations fall back to English.

Twenty-two UTF-8 JSON packs cover 679 messages each, including the in-app guide: Arabic, Bengali, German, Spanish, Persian, French, Hebrew, Hindi, Indonesian, Italian, Japanese, Punjabi in Gurmukhi and Shahmukhi scripts, Nigerian Pidgin, Brazilian Portuguese, Russian, Swahili, Ukrainian, Urdu, Vietnamese, and Simplified and Traditional Chinese.

Bundled fonts, bidirectional ordering and improved wrapping support these scripts. Independent native-speaker proofreading remains welcome. Right-to-left text is supported; the complete ribbon layout is not mirrored. Native operating-system dialogs retain the system language.

## Drawing controls

Enable Canvas controls in Settings to enter a drawing position, move by a chosen pixel step, click with either color, and start or finish a stroke through separate buttons. Checkbox controls replace held shape modifiers. Drawing coordinates remain tied to the original image when the working view is rotated.

Spirograph peg activation can seat a peg without dragging and resize a selected peg without losing its ink. On the custom pattern canvas, arrows choose a pixel, Space paints black and Enter paints white.

The application exposes names, roles, values and actions through macOS accessibility, Windows MSAA and Linux AT-SPI. Dialogs and popups limit the accessible controls to the active interaction. Voice Control, switch scanning, eye tracking and screen-reader usability still require end-to-end testing; protocol tests alone do not establish universal access.

## Installation and compatibility

The Forms interface remains the primary application. The deprecated SDL/ImGui frontend is not packaged. Existing settings are read by the new version; saved pictures remain ordinary image files.

Distribute the complete package, including fonts, language packs and runtime libraries. English continues to work if optional language packs are removed. macOS builds use an ad-hoc signature and are not Developer ID notarized. Linux requires X11 or XWayland; assistive technologies also require the desktop accessibility bus.
