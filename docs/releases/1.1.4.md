# Plan Paint 1.1.4

Plan Paint 1.1.4 updates GUI.Forms to improve Windows input handling and repainting.

- Keyboard and mouse input receive regular processing opportunities while application repaint messages are queued. Ordinary queued work continues to make progress.
- Translated text stays ahead of later keystrokes, preventing a later Backspace from overtaking a character that Windows has already translated.
- Repaints include the complete native update bounds even when a smaller logical update is pending. This addresses stale pixel edges and missed exposed areas.

The classic Windows 7/10 Paint ribbon, path editing, stamps, custom patterns and reshape tools remain available. Existing dropdown, cursor, language, font fallback, accessibility and Alt+F4 corrections are included in the new toolkit snapshot.

## Source and builds

The checksum-pinned GUI.Forms snapshot is commit `814ef16a714c4d8f9f75b3a80fcb36b1888a21c8` from `falseywinchnet/file_manager`, directory `gui_forms`. The archive is included with this release for reproducible source builds. No additional toolkit patches are required. The optional transactional DIB development backend remains disabled.

Packages target Windows x64, Apple Silicon macOS, Linux x64 and Linux ARM64. macOS requires version 26 or newer; its application is ad-hoc signed and its installer is unsigned. Linux requires X11 or XWayland. Windows 7/10 describes the familiar interface; Windows 7 operating-system support has not been verified.
