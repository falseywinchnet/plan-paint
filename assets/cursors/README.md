# Cursor artwork

Author: Astra

Sponsor: Rainstar

`tool-sheet.png` is the editable straight-alpha PNG master, drawn with Pencil
and Fill in Rainstar Paint. Sixteen 32-pixel cells use the Tool enum order:
Select, Lasso, Pencil, Fill / Text, Eraser, Picker, Magnifier /
Brush, Shape, Path, Stamp / Reshape, Guide, Freehand, Spirograph.

The little dark triangles are functional contact points. Pencil, brush,
eraser and dropper use their shaped working ends. Magnifier and text use their
centers. Keep these aligned with the hotspot table when editing the master.
See `docs/CUSTOM_CURSORS.md` for regeneration and validation.
